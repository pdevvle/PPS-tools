Connect Stripe

  1. In the Stripe Dashboard → Developers → API keys, copy your secret key (or create a restricted key with write access to Checkout Sessions, Payment Intents, Customers and Refunds, and read access to Charges, Balance, Balance Transactions and Payouts).

  3. Add a webhook endpoint pointing to {{ webhook_url }} for checkout.session.completed, checkout.session.async_payment_succeeded, checkout.session.async_payment_failed, payment_intent.succeeded, charge.refunded, charge.dispute.created, charge.dispute.closed, payout.paid and payout.failed, then save its signing secret.
