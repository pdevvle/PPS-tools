Road data for the road pass (`tools/stream/roads-bake.js`), downloaded with `tools/osm/roadfetch.sh` on 4 October 2026: every road in the New River block with all its tags, and the stops, speed signs, exit numbers, gates and cattle guards mapped on them. `osm_power_newriver.json` has the power lines, poles and substation (fetched the same day with the query in `tools/osm/roadfetch.sh`'s comments).
