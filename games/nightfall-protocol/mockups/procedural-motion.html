Character animation · procedural motion

No two moves alike

Every pose is a short list of joint angles, so motion can be varied the way faces are: within limits, and from a seed. Three layers stack on top of each other. All of the figures below are live and running the same code.

Layer 1 · fixed per person

Everyone has their own walk

The seed that builds a face also sets a few movement traits. Six people run the same walk cycle, each with their own stride, arm swing, posture and pace.

  • Same seed, same walk, every time
  • A veteran is recognisable by how they move
Layer 2 · rolled per action

Every action lands a little differently

Each time an action plays, its joint angles get a random offset inside set bounds. The faint figures are earlier rolls of the same "take cover" crouch; the solid one is the newest.

  • Elbows ±10°, knees ±9°, head ±7°, spine ±4°
  • Bounds per joint, so no pose is impossible
Layer 3 · continuous

Standing still is never still

Smooth noise keeps a held pose alive: weight shifts, breathing, small head turns. The trace shows three joints over the last six seconds, each wandering inside its shaded band.

What never varies

Hands on the weaponHand positions are solved to the grip, so noise moves the elbows and shoulders, not the hands.
The aim lineSway comes only from the soldier's Aim stat, as in the first-person shot, never from cosmetic noise.
Feet on the groundHip height adjusts so knees can bend differently without feet sinking or floating.
